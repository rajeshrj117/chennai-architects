CHANGED IN V4
- Removed the Tailwind browser CDN script. Styles are now served from a compiled, minified tailwind.css (Tailwind v4.3.3, ~38 KB). This removes the runtime CSS compiler and the unstyled-flash risk.
- Verified offline: computed layout, size, spacing and typography of all 802 elements match v3 at desktop (1440px) and mobile (390px). Only sub-0.01% colour rounding differences exist.
- Added logo.png (512x512, square, transparent corners), rendered from the existing ET favicon design, and pointed the schema "logo" at it. Replace it with your real logo file (same filename) if you have one.

DEPLOY
1. Upload ALL files to the same site root: index.html, tailwind.css, logo.png, og-image.jpg, robots.txt, sitemap.xml. index.html will be unstyled if tailwind.css is missing.
2. Confirm https://www.earthtonedesignstudio.in/ is the preferred domain and any alternate domain (e.g. the vercel.app URL) redirects to it.
3. Confirm hello@earthtonedesignstudio.in is a working mailbox.
4. Optional: add long cache headers for tailwind.css, logo.png and og-image.jpg; if you update tailwind.css later, rename it (e.g. tailwind.v2.css) and update the link in index.html.
5. Test: Meta Sharing Debugger (refresh WhatsApp preview), Google Rich Results Test, PageSpeed Insights.
6. Submit /sitemap.xml in Google Search Console.
